# FF14 Srank Desktop v4.2.8 更新笔记

## 用户可见变更

- 同步数据支持四大区自动联选子服务器，支持逐台取消；再次选中大区时自动补全其子服务器。
- 服务器总览提供四大区快捷筛选；取消大区会清理该区所有服务器选择，包括桌面、平板、手机保存的筛选，全部取消后允许空列表。
- 同步进度按真实已选服务器计数，而不是服务器数乘以 S 怪数量。
- 面板显示桌面版本、桥接版本和本机端口；每服务器展示 API 请求与返回结构诊断。

## 桥接 / API 修复

- 桌面桥接端口从 8788 切换至 8790，防止继续误复用旧版桥接进程。
- 桌面只复用 `/health` 中 `bridgeVersion` 精确匹配 1.4.8 的匿名 S 怪服务；未知或旧服务明确视为冲突。
- 新桥接数据目录 `bear-bridge-data-v2` 与旧目录隔离；升级时复制旧缓存，保留原目录不删除。
- 匿名 Bear 会话 GET 根路径获取临时 CSRF / Cookie，仅内存持有；批量请求使用 `QueryDeathTimers` / `RankType=sRank`，Referer `/srank`。
- 仍采用四大区独立批次、缺失世界限速单服复核、Rank=5 / 世界 / 时间 / CD 资源校验、429 全局冷却和有限只读重试。
- 同步 100% 只代表目标请求已处理；空数组、校验异常、请求失败和有效记录分别显示，旧缓存不被空 / 错误响应清空。

## CD / 监控室

- 保持 Bear 逐只怪 `RespawnTimer` / `MaintTimer` 的正常 / 维护窗口规则。
- 同一击杀锚点下维护 / 正常窗口变化更新同一条记录，不产生重复行。
- 同步快照确认后重投影到新旧监控室和计算器；实质字段未变化不重复写盘。
