# FF14 Srank Desktop v4.2.3 更新笔记

## 修复内容

1. **修复同步完成但监控室未刷新**：同步快照确认后，无论新增记录数是否为 0，都会向嵌入式监控室推送最新首页绑定数据；同时派发击杀记录变更事件并刷新计算器快照。
2. **修复监控室数据未持久化**：击杀锚点或 CD 状态变化时会写入监控室本地状态，不再只在重复目标合并时保存。
3. **修复 S 怪名称空格差异**：名称归一化忽略空格、标点、符号和全半角差异；通过正式词条及别名映射规范名称。
4. **合并同名空白重复行**：在同一服务器、同一版本分组内按规范化名称去重，优先保留有效击杀锚点和 CD 状态。
5. **数据安全**：不同服务器、大区与版本不会跨范围合并；本地手动历史记录、手动 CD 覆盖和非 Bear 数据不会被批量删除。
6. **刷新诊断**：监控室向首页回传本次绑定应用确认及状态统计。
