# FF14 Srank Desktop v4.2.0 更新笔记

## Bear Tracker 同步链路专项

- 新增独立「同步数据」控制中心。
- 支持豆豆柴、陆行鸟、莫古力、猫小胖四大区多选，首次默认陆行鸟。使用四大区内置服务器表作为完整兜底，并合并 Bear 公开资源中新出现的服务器。
- 增加同步阶段、真实进度、服务器级状态、队列、最近同步 / 成功时间和错误信息。支持手动同步、暂停、恢复。
- 远端批量请求没有逐世界流式回报时，进度在等待响应阶段保持不变；请求返回后按实际校验与持久化工作推进，不用计时器伪造百分比。
- 本机缓存每 30 秒检查并投影到工具箱；Bear 远端抓取继续由 S 怪 CD 窗口调度，避免 30 秒重复抓取。
- Bear 数据只导入 Rank=5 S 怪与有效击杀时间；服务器归属、怪物映射、时间范围和重复数据均需通过校验。网络失败或响应结构异常不会清空旧缓存。
- 更新同一服务器 / 同一 S 怪时，只替换较旧的 Bear 来源记录；手动数据、计算器数据及其他本地记录保留。
- 首次使用提示玩家先选择常用大区，保存后等待首次完整同步；可对照 Bear Tracker 公开计时页 https://tracker.beartoolkit.com/timer，不需填写账号密码。

## 监控室与计算器联动

- 监控室使用主工具箱的服务器分组和 S 怪词库，四大区服务器可切换；内置服务器表保证已有世界完整显示，并追加上游资源新增的世界，旧版和新版布局共享同一份同步记录。
- 计算器根据当前所选服务器 / S 怪显示最近击杀锚点，并实时计算 CD 剩余、预计进闸、存活窗口与强制时间；只在玩家主动点击时将击杀锚点填入表单，不覆盖正在编辑的数值。
- 计算器结果自动同步扩展到四大区正式服务器。

## 界面与本地保存

- 全局本地自动保存改为每 15 秒将脏数据写入 IndexedDB（不可用时回退到受限 localStorage）；离开页面或隐藏时尽力即时保存。
- 移除右下角自动保存悬浮入口和统一工具浮窗中的自动保存页签，减少占位。恢复草稿能力保留。
- 左侧导航将「排车指挥台」和「OCR 校准台」合并为「排车 / OCR 工具」折叠组，默认关闭；原页面和权限规则不变。

## 稳定性与隐私

- Bear Tracker 保持匿名只读，不上传击杀、账号或工具箱数据。
- 不主动删除用户数据；远端失败时旧缓存保留。
- 远端调度与本地快照刷新分离；30 秒周期不代表每 30 秒向 Bear 站点发起请求。
- 本次本地测试：桌面端 13/13、桥接端 17/17 通过；语法检查通过。Windows EXE 构建、首次启动以及真实 Bear 在线同步仍须在 GitHub Actions / Windows 环境验证后才算正式发布。
