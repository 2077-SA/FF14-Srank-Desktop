# FF14 Srank Desktop

当前工程版本：**v4.2.1**（四大区 CD 数据隔离修复；Windows 云端构建待运行验证）。

## v4.2.1 核心修复：四大区隔离

- 豆豆柴、陆行鸟、莫古力、猫小胖分别使用独立的 S 怪缓存分区、同步状态元数据和下次检查时间。
- 每条击杀记录写入前必须匹配“大区 + 子服务器 + S 怪”归属。未知世界、归属冲突和跨区写入会被拒绝。
- 本地 API 支持按大区读取；单只 S 怪查询也会校验世界与大区，不允许跨区读取。
- 计算器的本地索引和 Bear 同步替换键加入大区字段，只读取当前服务器所属大区的锚点。
- 旧版共享 state.json 会按服务器归属迁移到四个分区；无法唯一映射的旧记录单独隔离保留，不参加 CD 计算，也不删除原文件。
- 每个大区独立保存最近成功时间、失败状态、错误和下次同步时间；一个大区失败不会改写其他大区的缓存。

## 保留的 v4.2.0 功能

- 独立「同步数据」控制中心，四大区多选，首次默认陆行鸟。
- 真实同步阶段进度、服务器级状态、手动同步、暂停和恢复。
- 新版 / 旧版监控室及计算器共享同步记录。
- 30 秒本地缓存投影；远端 Bear 请求仍按 CD 窗口调度。
- 每 15 秒静默自动保存；排车 / OCR 合并为默认折叠菜单。
- Bear Tracker 匿名只读，仅处理 Rank=5 S 怪，不登录、不向上游写入。

## 下载和发布

正式安装版和 Portable 便携版构建后可从 [GitHub Releases](https://github.com/2077-SA/FF14-Srank-Desktop/releases) 下载。

发布 v4.2.1：
1. 将 `FF14_Srank_Desktop_v4.2.1_工程源码.zip` 上传到仓库根目录。
2. 打开 GitHub **Actions**。
3. 运行 **Build and publish FF14 Srank Desktop release**。
4. 工作流将先执行语法检查和自动化测试，再构建 Windows 安装版与 Portable 版并发布更新元数据。

本地用户数据保存在 Electron `userData` 目录，与安装目录分离。升级不会主动清空用户数据；旧版无法准确识别归属的记录会隔离保留，等待核对。
