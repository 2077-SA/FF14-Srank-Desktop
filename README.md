# FF14 Srank Desktop

当前版本：v4.1.2（Windows）

## 下载

打开 [Releases](https://github.com/2077-SA/FF14-Srank-Desktop/releases)，选择最新版本：

- **安装版**：`FF14-Srank-Desktop-4.1.2-x64.exe`，双击安装，适合长期使用。
- **便携版**：`FF14-Srank-Desktop-4.1.2-Portable-x64.exe`，解压后直接运行，不写入安装目录。

## 使用

1. 下载对应版本 EXE。
2. 安装版双击安装；便携版直接运行。
3. 首次启动后按界面提示选择数据中心并保存。

本地设置、CD 和已有记录会保留；本次更新不会主动清空用户数据。
